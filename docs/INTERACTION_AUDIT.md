# Аудит интерактивных элементов

Дата: 2026-09-11. Карта покрывает все пользовательские контролы приложения: повторяющиеся строки описаны как один тип контроля (`{тренировка}`, `{подход}`, `{упражнение}`), а не как сотни одинаковых экземпляров.

## Контексты, по которым проверялось поведение

| Код | Контекст |
| --- | --- |
| `EMPTY` | нет данных / первый запуск |
| `OFFLINE` | нет сети, есть или нет локального кэша |
| `ERROR` | сервер или валидация вернули ошибку |
| `ACTIVE` | есть незавершённая силовая или аэробная тренировка |
| `PRO` | лимит бесплатного плана / известный статус Pro |
| `EDIT` | редактирование данных, в том числе завершённой тренировки |

## Вход и глобальная навигация

| Контрол | Нажатие | Контексты и ожидаемый результат |
| --- | --- | --- |
| Войти | Проверяет e-mail/пароль, запускает вход | Ошибка остаётся на экране; во время запроса кнопка блокируется. |
| Продолжить с Google | Запускает OAuth | Во время авторизации блокируется; отмена возвращает на экран входа. |
| Создать аккаунт / Уже есть аккаунт | Меняет экран регистрации и входа | Не изменяет введённые данные сервера. |
| Луна/солнце | Переключает светлую и тёмную тему | Настройка сохраняется и синхронизируется. |
| Назад в шапке | Возвращает на предыдущий экран | На корневом экране не закрывает приложение. |
| Нижняя навигация (если показана) | Открывает выбранный раздел | Активная вкладка не создаёт дубликат перехода; есть haptic feedback. |
| Баннер офлайна с отклонёнными изменениями | Повторяет отправку rejected outbox | `OFFLINE`: не делает ложного «успеха», ждёт сеть. |

## Экран «Сегодня»

| Контрол | Нажатие | Контексты и ожидаемый результат |
| --- | --- | --- |
| Основное действие карточки «Сегодня» | Открывает выбор тренировок, плановую тренировку или продолжает активную | `ACTIVE`: восстанавливает нужный runner, не создаёт вторую сессию. |
| Значок и подпись Passport | Открывают Strength Passport | `EMPTY`: показывают пример паспорта и маршрут к первой записи. |
| Полоса серии / целей / рутин | Открывает годовой календарь | Не меняет серию; только просмотр. |
| Разделы: Тренировки, Прогресс, Passport, Упражнения, Настройки | Переходят в соответствующий раздел | Возврат обновляет карточки «Сегодня». |
| «Начать тренировку» | Открывает тренировки | `EMPTY`: ведёт к созданию, а не к пустому runner. |
| Training brief | Открывает Passport | Работает и без рангов. |

## Тренировки, библиотека и папки

| Контрол | Нажатие | Контексты и ожидаемый результат |
| --- | --- | --- |
| Мои / Библиотека | Переключает источник | Библиотека загружается лениво; ошибка показывает Retry. |
| Поиск | Фильтрует имя, заметку и мышечные группы | Пустой результат показывает отдельное состояние. |
| Сортировка | Recently updated / Most performed / Name | Меняет только порядок текущего списка. |
| Фильтры библиотеки: цель и мышца | Сужают библиотеку | Не удаляют рутины и комбинируются с поиском. |
| Папка / Default | Меняет отображаемую папку | Поиск временно показывает все подходящие рутины. |
| Новая папка | Запрашивает имя, создаёт папку | `PRO`: без Pro открывается paywall; `OFFLINE`: ставит изменение в outbox. |
| Меню папки | Rename или Delete | Удаление требует явного «Delete everything» и объясняет число рутин. |
| Карточка `{тренировка}` | Открывает детали | Полный план догружается перед стартом; офлайн не стартует из неполной карточки. |
| Меню карточки | Открывает действия с собственной/публичной тренировкой | Публичный шаблон можно сохранить копией, а не менять оригинал. |
| Молния «Начать сейчас» | Выбор одной из силовых рутин и запуск без деталей | `EMPTY`: ведёт к созданию; `ACTIVE`: возобновляет текущую, не перезаписывает её. |
| Календарь | Открывает программы | Не требует Pro сам по себе. |
| Плюс | Создаёт рутину | После 5 рутин проверяет Pro; неопределённый статус не трактует как бесплатный. |

## Редактор рутины и выбор упражнения

| Контрол | Нажатие | Контексты и ожидаемый результат |
| --- | --- | --- |
| Gym / Aerobic | Меняет тип новой рутины | Переход в Aerobic очищает силовые упражнения осознанно; aerobic можно сохранить без упражнений. |
| Add exercise | Открывает picker | Исключает уже добавленные упражнения. |

| Тип `{подхода}` | Циклически меняет warm-up / working / failure / dropset | Состояние сохраняется в плане. |
| Удалить подход | Удаляет подход | Последний подход не удаляется. |
| Add set | Добавляет подход | Копирует предыдущее безопасное начальное значение. |
| Up / Down | Меняет порядок упражнения | На границах кнопка не меняет список. |
| Save range / Remove guardrail | Сохраняет или снимает ограничение повторов | Работает только у упражнений с повторами. |
| SAVE / CREATE | Сохраняет план | `ERROR`: показывает конкретную валидацию или ошибку; `OFFLINE`: сохраняет локально и ставит sync. |
| Picker: All / Recent / Favorites, мышцы, оборудование | Фильтрует каталог | Сочетается с поиском; не меняет каталог. |
| Звезда в picker | Добавляет/удаляет избранное | Локально доступно сразу, затем синхронизируется. |
| `{упражнение}` в picker | Выбирает его и возвращает в редактор | Нельзя выбрать уже добавленный ID. |

## Силовая тренировка

| Контрол | Нажатие | Контексты и ожидаемый результат |
| --- | --- | --- |
| Свернуть | Сворачивает runner | `ACTIVE`: состояние и Live Activity сохраняются. |
| Закрыть | Спрашивает о выходе | Keep going ничего не теряет; Quit не завершает случайно. |
| Finish | Предлагает discard / save / update routine | Отправляется один раз; во время завершения заблокирован. |
| Меню упражнения | Note, group, ungroup, move, remove | Удаление очищает контроллеры подходов; grouping доступен только совместимому следующему упражнению. |
| Note | Редактирует заметку упражнения | Сохраняется в активной сессии. |
| Add warm-ups | Добавляет рассчитанные разминки | Не добавляет дубликаты или веса выше рабочего. |
| Previous | Подставляет предыдущий подход | Недоступен у завершённого подхода. |
| RPE | Выбирает 6–10 или очищает | Недоступен у завершённого подхода. |
| Тип подхода / progression | Открывают picker типа и тега | Завершённый подход неизменяем. |
| Галочка подхода | Логирует подход и запускает отдых | При выходе за плановый диапазон красит значение и спрашивает подтверждение. |
| Таймер отдыха: плюс / минус / Skip | Настраивает или пропускает отдых | Не меняет уже залогированный вес/повторы. |
| Share record / Close completion | Делится карточкой или закрывает completion | Ошибка share показывается, закрытие не повторяет сохранение. |

## Найдено и исправлено этим аудитом

1. Архивация программы удаляла её одним тапом. Теперь есть подтверждение и точное объяснение области удаления.
2. Ошибка загрузки программ выглядела как пустой список. Теперь есть отдельный экран ошибки и Retry.
3. Создание программы не показывало ошибку сохранения. Теперь показывается понятный диалог, рутины не меняются.
4. Быстрый выбор «Год / Все» мог оставить подпись периода от одного запроса и данные от другого. Теперь устаревшие ответы игнорируются, а период меняется только с полученными данными.
5. Удалённое упражнение в редакторе не освобождало свои контроллеры ввода. Теперь освобождает.
